    Made for blast radius

    MergeAtlas is for changes that reach further than their diff: several files, some of them affected only indirectly, in a project you don't know well.

    A config tweak doesn't need a map. Your agent or the PR description can tell you what it touches.

    The map stops at understanding. It doesn't find bugs, give verdicts, or tell you what to do. Those stay with you.

    Map your next review

    You need an agent that runs skills, such as Claude Code, plus Python 3, git, and the GitHub CLI signed in.

    git clone https://github.com/ismayilkarimli/MergeAtlas.git
    ln -s "$PWD/MergeAtlas/skills/mergeatlas" ~/.claude/skills/mergeatlas

    From inside the PR's repository, ask your agent to map it, or run /mergeatlas in Claude Code. Your maps stay on your machine.
